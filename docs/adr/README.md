# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Herbal.ma.

## Rules

- Read relevant ADRs before changing architecture.
- New architectural decisions require a new ADR and explicit approval.
- Accepted ADRs are historical records. Do not rewrite an accepted decision to mean something different.
- When a decision changes, add a new ADR that supersedes the old one and update this index.
- Keep ADRs short, decision-focused, and consistent with PROJECT.md and ARCHITECTURE.md.
