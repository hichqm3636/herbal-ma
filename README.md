# Herbal.ma

Herbal.ma is an independent, content-first knowledge platform about dietary supplements, herbs, nutrition, wellness, product labels, and formulations. Arabic is the primary language and English is the secondary language.

## Current status

The project is in **Phase 0: foundation and documentation**. Implementation has not started. Astro has not been initialized, no dependencies have been installed, and no hosting, database, authentication, CMS, or CI/CD has been configured.
